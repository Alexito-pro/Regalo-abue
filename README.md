# Mis abuelitos, mi lugar feliz

Un álbum familiar alegre y adaptable a móvil, hecho con HTML, CSS y JavaScript sin dependencias. Las 19 fotos actuales están en `fotos/`.

## Abrir en VS Code

Abre esta carpeta en Visual Studio Code. Puedes abrir `index.html` en el navegador o instalar **Live Server** y usar **Open with Live Server** para actualizar la página al guardar.

## Agregar más recuerdos

1. Copia la nueva foto a la carpeta `fotos/` y asígnale un nombre sencillo, por ejemplo `11-Foto-11.jpg`.
2. En `script.js`, agrega un elemento al arreglo `memories` con el nombre de archivo, una descripción de la foto y un pie de foto.

La galería y el visor se actualizan automáticamente con cada elemento de ese arreglo. Las imágenes se cargan al desplazarse para que el álbum abra más rápido. Las fuentes vienen de Google Fonts; sin conexión se usan fuentes alternativas.
